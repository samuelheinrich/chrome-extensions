# Bookmark Wizard Privacy Policy

Last updated: 2026-08-03

Bookmark Wizard is a local Chrome extension for managing Chrome bookmarks. It does not require an account and does not operate Bookmark Wizard servers for user data.

## Data Processed

Bookmark Wizard can process the following data locally in your browser:

- Bookmark titles, URLs, folder names and bookmark tree structure.
- Local settings such as deadlink timeout preferences.
- Local undo metadata for soft-deleted or moved bookmark items.
- Backup files only when you choose to export or import them.

## How Data Is Used

Data is used only to provide bookmark-management features:

- Search, sort, rename and organize bookmarks.
- Move bookmarks and folders using drag and drop.
- Soft-delete bookmarks into a local `Deleted` folder and restore them when possible.
- Export and import local JSON backups.
- Check whether bookmark URLs are reachable when you explicitly start a deadlink check.

## Deadlink Checks

Deadlink checks are always user-initiated. When you run a deadlink check, Chrome contacts the target bookmark URLs directly from your browser using HTTP/HTTPS requests. Bookmark Wizard does not send those URLs to Bookmark Wizard servers.

Private and local hosts are skipped by default, including `localhost`, `.local`, private IPv4 ranges and common private IPv6 ranges.

## Data Sharing

Bookmark Wizard does not sell, transfer or share your bookmark data with third parties. It does not include analytics, tracking pixels or telemetry.

The only network traffic caused by Bookmark Wizard is the user-triggered deadlink check to the bookmark target websites themselves.

## Storage

Bookmark Wizard stores local settings and undo metadata in `chrome.storage.local`. Chrome bookmarks remain stored by Chrome itself. Backup exports are downloaded locally to your device when you choose to create them.

## Data Deletion

You can delete Bookmark Wizard local settings by removing the extension from Chrome. Bookmarks are Chrome-managed user data and remain under your control in Chrome unless you modify or delete them with Bookmark Wizard.

## Remote Code

Bookmark Wizard does not execute remotely hosted code.

## Contact

For privacy questions, use the support contact or issue tracker provided in the Chrome Web Store listing.

# Datenschutzrichtlinie fuer Bookmark Wizard

Stand: 2026-08-03

Bookmark Wizard ist eine lokale Chrome-Erweiterung zur Verwaltung von Chrome-Lesezeichen. Es wird kein Konto benoetigt und Bookmark Wizard betreibt keine eigenen Server fuer Nutzerdaten.

## Verarbeitete Daten

Bookmark Wizard kann lokal im Browser folgende Daten verarbeiten:

- Bookmark-Titel, URLs, Ordnernamen und Bookmark-Struktur.
- Lokale Einstellungen wie Deadlink-Timeouts.
- Lokale Undo-Metadaten fuer geloeschte oder verschobene Bookmarks.
- Backup-Dateien nur wenn du Export oder Import aktiv nutzt.

## Nutzung Der Daten

Die Daten werden nur fuer Bookmark-Funktionen genutzt:

- Suchen, Sortieren, Umbenennen und Organisieren von Bookmarks.
- Verschieben von Bookmarks und Ordnern per Drag & Drop.
- Soft-Delete in den lokalen `Deleted`-Ordner und Wiederherstellung wenn moeglich.
- Lokaler Export und Import von JSON-Backups.
- Pruefen von Bookmark-URLs, wenn du explizit einen Deadlink-Check startest.

## Deadlink-Checks

Deadlink-Checks werden nur durch Nutzeraktion gestartet. Dabei kontaktiert Chrome die Ziel-URLs deiner Bookmarks direkt aus deinem Browser per HTTP/HTTPS. Bookmark Wizard sendet diese URLs nicht an Bookmark-Wizard-Server.

Private und lokale Hosts werden standardmaessig uebersprungen, darunter `localhost`, `.local`, private IPv4-Bereiche und gaengige private IPv6-Bereiche.

## Weitergabe Von Daten

Bookmark Wizard verkauft, uebertraegt oder teilt keine Bookmark-Daten mit Dritten. Es gibt keine Analytics, Tracking-Pixel oder Telemetrie.

Der einzige durch Bookmark Wizard ausgeloeste Netzwerkverkehr ist der nutzerinitiierte Deadlink-Check zu den jeweiligen Bookmark-Zielseiten.

## Speicherung

Bookmark Wizard speichert lokale Einstellungen und Undo-Metadaten in `chrome.storage.local`. Chrome-Lesezeichen bleiben von Chrome verwaltete Daten. Backup-Exporte werden lokal auf dein Geraet heruntergeladen, wenn du sie erstellst.

## Loeschung

Lokale Bookmark-Wizard-Einstellungen koennen durch Entfernen der Erweiterung aus Chrome geloescht werden. Bookmarks bleiben Chrome-Daten unter deiner Kontrolle, ausser du bearbeitest oder loeschst sie mit Bookmark Wizard.

## Remote Code

Bookmark Wizard fuehrt keinen remote gehosteten Code aus.

## Kontakt

Fuer Datenschutzfragen nutze den Support-Kontakt oder Issue Tracker aus dem Chrome-Web-Store-Eintrag.
